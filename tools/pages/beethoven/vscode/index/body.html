Beethoven for VS Code

Your grid. From VS Code.

One setup on your laptop. A Claude Code worker in your own grid account, on your own Claude subscription.

You need: a Wayne State AccessID· a grid account· GlobalProtect VPN· Claude Pro or Max· VS Code Ask for access →

What it does

  1. Sets up your laptop

    One wizard: an SSH key, a marked block in your SSH settings, sign-in through VS Code's own Microsoft and GitHub accounts, and your GitHub and Hugging Face tokens kept in your computer's credential store.

  2. Keeps a worker on the grid

    It installs its scripts in your own grid account and keeps a Claude Code worker running there as a Slurm job. You sign in to Claude yourself; Beethoven never reads, stores or copies your Claude sign-in.

  3. Reach it from VS Code or your phone

    Terminals and a side panel in VS Code, a link that lets the Claude on your laptop hand work to the worker, and Remote Control from the Claude app if you turn it on.

Install

One approval covers both editions: ask for access with your AccessID. Beethoven for VS Code runs Claude Code and is not an Anthropic product.
