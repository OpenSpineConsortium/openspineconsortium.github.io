Symphony

A team of Claude Code teammates. On your repository.

Install the App. Press Create. Merge the pull request. From then on every Claude Code session that opens your repository, on any account, claims an issue, works it in the open and lands it by pull request.

You need: a GitHub repository· Claude Pro or Max How it works →

Three presses

  1. Install the App

    On GitHub, install the Symphony App on the repository, new or old. For the repository's settings too (a ruleset, auto-merge, secret scanning), install the Setup App first: it holds Administration for the one run and uninstalls itself when done.

  2. Press Create

    GitHub sends you to a form with your installation already filled in. Press Create: the kind of repository is read from its files, an empty one gets the whole template and one with files gets the claim protocol alone.

  3. Merge the pull request

    Within about two minutes a pull request lands in your repository with everything the teammates need, from the Symphony App and nobody else. Tick "Merge the pull request for me" on the form and it merges itself.

Start

On GitHub

Install the Symphony App Install the Setup App too

The App opens pull requests and reads your repository; it never holds Administration. The Setup App applies the settings for one run, then uninstalls itself.

In Chrome

Symphony for Chrome: Chrome Web Store listing pending review.

It adds one button to GitHub's new-repository page, "Create Symphony repository", and one to every repository's header, "Migrate to Symphony", each opening the App's install page. It runs on github.com only, sends nothing to anyone and keeps nothing but a fifteen-minute note of the repository you just made. Privacy statement

In Claude Code

A repository Symphony set up needs nothing installed: its instructions, its board and its hooks are files in the repository, and every session reads them. The symphony plugin brings the same procedures and fences to a repository that was not.

What is shared: counts, durations and rates of the protocol at work, never code, text or names, with one switch off. Symphony is not a GitHub or Anthropic product. "GitHub" is GitHub's mark; "Claude" and "Claude Code" are Anthropic's marks, used here to say what Symphony works with.
