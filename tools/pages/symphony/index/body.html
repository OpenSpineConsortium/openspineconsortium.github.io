Symphony

A team of Claude Code teammates. On your repository.

Install the App. Press Create. Merge the pull request. From then on every Claude Code session that opens your repository, on any account, claims an issue, works it in the open and lands it by pull request.

You need: a GitHub repository· Claude Pro or Max How it works →

Three presses

  1. Install the two Apps

    On GitHub, install SymphonyBoard on the repository, new or old, and Symphony Setup on it too: the first opens the pull request, the second applies the repository's settings (a ruleset, auto-merge, secret scanning) for the one run and uninstalls itself when done. Installing SymphonyBoard takes you on to Symphony Setup's install page, and that install to the form; from the Chrome extension's button, both pages come with that repository already selected.

  2. Press Create

    GitHub sends you to a form with your installation, and from the extension your repository, already filled in. Press Create: the kind of repository is read from its files, an empty one gets the whole template and one with files gets the claim protocol alone.

  3. Merge the pull request

    Within about two minutes a pull request lands in your repository with everything the teammates need, from the Symphony App and nobody else. The form merges it for you unless you choose to review it first.

Start

On GitHub

Install SymphonyBoard Install Symphony Setup too

Both are needed. SymphonyBoard opens pull requests and reads your repository; it never holds Administration. Symphony Setup applies the settings for one run, then uninstalls itself. Privacy statement for the Apps

In Chrome

Symphony for Chrome: Chrome Web Store listing pending review.

It adds one button to GitHub's new-repository page, "Create Symphony repository", and one to every repository's header, "Migrate to Symphony", which open the Apps' install pages with that repository already selected and carry its name to the form. It runs on github.com only, sends nothing to anyone and keeps nothing but two short-lived notes of the repository you pressed the button on. Privacy statement

In Claude Code

A repository Symphony set up needs nothing installed: its instructions, its board and its hooks are files in the repository, and every session reads them. The symphony plugin brings the same procedures and fences to a repository that was not.

What is shared: counts, durations and rates of the protocol at work, never code, text or names, with one switch off. Symphony is not a GitHub or Anthropic product. "GitHub" is GitHub's mark; "Claude" and "Claude Code" are Anthropic's marks, used here to say what Symphony works with.
