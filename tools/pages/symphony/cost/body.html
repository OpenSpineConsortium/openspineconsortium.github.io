Symphony

What it costs

Symphony’s bill is a flat Claude plan and, on a public repository, nothing for compute: the workers run in GitHub Actions on the repository’s own subscription token, and standard runners are free and unlimited on public repositories. The other ways of running coding agents on GitHub meter every token. This page prices the same work under each: measured on your repository when you are signed in to the control panel, or from the numbers you type below. Every price has its source at the foot of the page.

Measured on your repository

A Symphony repository records what its work cost beside the work: each session’s commits carry a Symphony-Usage line and each Claude run in Actions leaves a usage record, and the metrics workflow sums them daily into METRICS.json on the branch metrics, priced at Anthropic’s API list prices, with no API key, no routine and no server. Signed in, the page reads that file as you and sets the figure beside what you paid instead.

Sign in

One press, as on the control panel: GitHub sends you straight back here signed in, and the page reads the file as you.

Sign in with GitHub switches on once its sign-in service is running; until then, use a token below.

Use a fine-grained token instead The same token as the control panel’s; it stays in this browser and goes to GitHub’s API only. Make one at github.com/settings/personal-access-tokens/new.

Price the same work under each system

Type a month of agent runs, or press the button above to take your repository’s last 30 days. The defaults are a typical 40-turn run in Actions: most of its tokens are cache reads, which is why a flat plan goes far.

A Claude plan’s allowance is published as a multiple, not a token count: Anthropic says Pro gives at least five times Free per five-hour window and Max five or twenty times Pro, with weekly limits on top; past them, usage credits bill at the API prices in the table. Cache writes are priced at the five-minute rate, which an API key gets by default; on a subscription the cache lives an hour.

How each system charges

The cost model of each way of running coding agents on GitHub, read from each project’s own documents and code on 2026-10-15. Symphony is the only one of them that runs its agents in Actions on a flat Claude plan: the Actions-native neighbors take an API key or Copilot credits and refuse the subscription token, and the flat-plan neighbors run their agents on people’s own machines.

Sources

  • Claude plans: claude.com/pricing (Pro $20 monthly, Max 5x $100, Max 20x $200; limits as multiples per five-hour window, weekly limits on top; read 2026-10-15) and usage credits at API rates past the limits.
  • Claude Code in Actions on a subscription: Anthropic’s GitHub Actions page (“If you authenticate with an OAuth token, runs use your Claude subscription instead of API billing”), which is how a Symphony repository’s workers run.
  • API list prices: platform.claude.com, pricing (read 2026-10-15). The field metrics a repository records are priced by the Symphony template’s own table (tools/economics.py) as of the date it names, which the page prints beside the measured figures; the two tables can differ until the template takes a price change.
  • GitHub Actions: github/docs, billing for GitHub Actions (free and unlimited standard runners on public repositories; 2,000 minutes a month on Free, 3,000 on Pro and Team; Linux 2-core $0.006 a minute from 2026-01-01; read at commit 12691d2, 2026-10-15).
  • GitHub Copilot: github/docs, Copilot billing (usage-based since 2026-06-01, AI credits at $0.01; Pro $10 with 1,500 credits, Pro+ $39 with 7,000, Max $100 with 20,000) and about third-party coding agents (they consume Actions minutes and AI credits) and models and pricing (Claude at Anthropic’s list prices).
  • GitHub Agentic Workflows: gh-aw, the Claude engine (“Claude subscription OAuth tokens such as CLAUDE_CODE_OAUTH_TOKEN are not supported”; read at commit dc91dbe, 2026-10-15).
  • OpenAI: openai/codex-action (an API key as a secret is required).
  • unsorry: agenticsnz/unsorry at commit 029d328b (ADR-004 for the claims on one shared branch, reaper.yml and queue-dispatcher.yml for the coordination in Actions, swarm/agent.sh for each volunteer’s own runs; read 2026-10-15).
