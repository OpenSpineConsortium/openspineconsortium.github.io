Read a repository

Sign in with GitHub to read a repository your account can read: its folders, its documents rendered, its pictures, and its HTML pages shown sealed in a frame that cannot reach your sign-in or this site and can send next to nothing out. The page asks GitHub’s API from this browser as you, so it shows exactly what your own account may see, and it keeps nothing but the sign-in, in this browser. Name the repository in the address as ?repo=OWNER/NAME, or choose one below from those listed on the control panel, which writes it into the address.

Sign in

Sign in with GitHub to read a repository your account can read. One press, as on the control panel: GitHub sends you straight back here signed in.

Sign in with GitHub switches on once its sign-in service is running; until then, use a token below.

Use a fine-grained token instead The same token as the control panel’s; it stays in this browser and goes to GitHub’s API only. Make one at github.com/settings/personal-access-tokens/new.
